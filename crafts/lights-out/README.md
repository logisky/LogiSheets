# lights-out (关灯)

The classic **Lights Out** puzzle on a LogiSheets grid. Click a cell and it
toggles that cell **and its four orthogonal neighbors** (up/down/left/right).
Turn every light off to win.

## How it works (reuses the fuse-beads / memory-grid patterns)

- Own worksheet `关灯`, a 5×5 square-cell board created once via `ensureBoard`
  (created, never deleted — reused and repainted), framed with a thin inner grid
  + a thick outer boundary.
- Lit / unlit cells are pattern fills (`{red,green,blue}` object). Border colors
  are the engine's **standard ARGB strings** (8 hex digits, no `#`).
- `window.onCanvasInput` — a left mousedown on a board cell applies the move;
  mousedown is always consumed (blocks the selection box and double-click edit).
  `window.setSelectionSuppressed(true)` hides the selection highlight.
- **Puzzles are always solvable**: generated by starting from all-off and
  applying N random clicks (each click is its own inverse), where N is the
  difficulty (easy 4 / medium 8 / hard 14).
- **Progress** (`window.getCraftState` / `setCraftState`): `{ solved, best,
  difficulty, board, moves }` — resumes the current puzzle and remembers your
  fewest-moves record. Includes 新游戏 / 重玩本局 / 重置进度.

## Build

```bash
yarn build   # vite (UMD) → copies index.html + lights-out.js to public/lights-out/
```
